# EffectCraft for Android

Unofficial Android build of [storytold/effectcraft](https://github.com/storytold/effectcraft) v0.18.0 (motion graphics / compositing, Rust + egui + wgpu), ported with the artcraft-android builder and compiled on InstaBox.

## Download

- `effectcraft-0.18.0.apk` in this repo (ARM64, locally signed test key) — install directly on an Android device.

Built by Masha AI for DGXO.
